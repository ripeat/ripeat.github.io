Appearance

Set up any machine from a list of tools, and undo it safely.

ripeat shows the plan and its risk, asks before it changes anything, and keeps a journal so every run can be rolled back.

Copy the prompt, then paste it into your agent · or install from the terminal:
$ brew install ripeat/tap/ripeat

macOS

Homebrew, Intel and Apple silicon. Every change is shown first and can be undone.

Linux

Homebrew too, x86_64 and arm64. ripeat also drives apt, dnf, pacman, snap and flatpak.

Windows

Scoop, x86_64 and arm64. Needs git once, to add the bucket.

A first look ​

These commands only look. They change nothing.

console
$ ripeat plan git node ripgrep
Plan (darwin):
  1. git          -               user   already on this machine, will be left alone
  2. node         -               user   already on this machine, will be left alone
  3. ripgrep      github_release  user   requested

$ ripeat assess ripgrep
Risk: MEDIUM   1 to install

  RISK      TOOL     HOW             WHY
  MEDIUM    ripgrep  github_release  requested
                     - downloads a program from a third party: its SHA-256 is
                       verified, but ripeat cannot vouch for the project itself

What would run, without administrator rights:
  download the latest BurntSushi/ripgrep release for this machine, check its SHA-256, ...

Can it be undone? Yes: `ripeat rollback` removes what this run installs

When you are ready, ripeat install ripgrep shows the plan again, asks Install 1 tool as shown above? [y/N], and only then changes anything. ripeat rollback undoes it.
